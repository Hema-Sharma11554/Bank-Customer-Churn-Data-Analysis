# Bank Churn Analysis Dashboard

## 📌 Project Overview
This dashboard provides a detailed analysis of customer churn for a fictional bank, helping identify key factors contributing to customer loss. 
Built using Power BI, it visualizes demographic, behavioral, and financial attributes to support strategic decision-making.

## 📊 Key Metrics
- **Total Customers:** 10,000  
- **Lost Customers:** 2,037  
- **Churn Rate:** 20.4%

## 🔍 Visual Insights
- **Age Group Analysis:** Customers >50 have the highest churn (~35%)
- **Salary Segmentation:** Lower income groups show higher churn
- **Product Usage:** Single-product holders are more likely to churn
- **Geography & Activity:** France leads in customer base; inactivity correlates with churn

## 🛠 Tools & Skills
- Power BI for dashboard creation  
- DAX for calculated metrics  
- Data storytelling and business interpretation
